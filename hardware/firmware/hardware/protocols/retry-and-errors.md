# 错误码、超时与重试

适用于全部设备侧 HTTP / WebSocket 交互。目标是让"网络抖一下"不至于把设备逼进死循环，
也让排障时能从日志一眼看出是凭证问题还是网络问题。

## 1. HTTP 状态码处理策略

| 状态码 | 含义 | 设备动作 | 是否重试 |
|---|---|---|---|
| `200` / `201` / `204` | 成功 | 继续正常节奏 | — |
| `400` | 字段/格式错 | **记日志并停止重试**，对照协议改固件 | 否 |
| `401` / `403` | 令牌错误或未授权 | 记日志 + 状态灯报错；**不要空转重试**（会把账号/服务打满） | 否（等人工修配置） |
| `404` | 资源不存在（如云台状态尚未回报） | 视为"设备未上线"，继续正常轮询 | 是（按正常节奏） |
| `408` / `429` | 超时 / 限流 | 退避后重试 | 是 |
| `5xx` | 服务端错误 | 退避后重试 | 是 |
| 无响应/连接失败 | 网络不可达 | 退避后重试；连续 10 次失败可触发重连 Wi-Fi | 是 |

**401 不要重试**是硬规则：固件里 token 是编译期常量，重试一万次也不会变对，只会把日志刷满。

## 2. 退避策略

指数退避 + 上限，避免雪崩：

```text
第 1 次失败：立即（或 200 ms）
第 2 次：     500 ms
第 3 次：     1 s
第 4 次：     2 s
之后：        4 s（封顶，不再增长）
恢复成功：    重置为初始值
```

WebSocket 重连（后端 `HARDWARE_PROTOCOL.md` 明确要求）：**1、2、4、8、15 秒**，
且重连成功后必须重新发送 `hello`。

## 3. 超时建议

| 请求类型 | 超时 | 依据 |
|---|---|---|
| 体征上报 | 3 s | 报文 < 300 B，局域网内 100 ms 级 |
| 摄像头单帧 | 10 s | VGA 单帧 30–60 KB，弱网留余量 |
| 云台指令拉取 | 3 s | 每 5 s 轮询一次，不能阻塞太久 |
| 云台状态回报 | 3 s | |
| 整段语音上传 | 20 s | 30 s 音频 + ASR + TTS，后端 `proxy_read_timeout 180s` |
| 流式 PCM 下载 | 30 s（整轮） | chunked 响应，不依赖 Content-Length |
| 测试音下载 | 15 s | |

## 4. 云端错误码

语音服务与阿里云返回 JSON 错误时，设备**必须先把状态码当音频/JSON 判断，不能直接播放**：

```json
{"type":"error","code":"device_token_invalid","message":"设备凭据无效"}
```

| `code` | 含义 | 设备动作 |
|---|---|---|
| `device_token_invalid` | `X-Device-Token` 与后端不一致 | 停止重连，打印配置提示 |
| `unsupported_audio` | 音频格式/采样率不被接受 | 检查 16 kHz / 16 bit / mono |
| `asr_failed` | 识别失败（通常是静音或噪声） | 忽略本轮，回到 VAD 等待 |
| `tts_failed` | 合成失败 | 忽略本轮 |
| `upstream_unavailable` | 大模型/语音供应商不可用 | 退避后重试一次 |

## 5. 设备端日志约定

排障靠日志，统一用 ESP_LOGI/W/E，并带上模块 TAG：

| TAG | 模块 | 关键日志 |
|---|---|---|
| `mqtt` / `aliot` | `main.c` / `mqtt_aliot.c` | Wi-Fi 连接、IP、MQTT 连接 |
| `HTTP_UPLOAD` | `main.c` | `sensor upload status=200` |
| `camera` | `camera.c` | `Camera initialized`、`Upload failed` |
| `servo` | `servo.c` | `Fetched target_angle=45`、`report sent` |
| `voice_input` / `voice_output` / `voice_stream` | 语音三件套 | 录音起止、播放起止、WS 事件 |

建议日志里**不要打印完整 Token**（只打印前 6 位 + 长度），避免串口日志被截图外泄。

## 6. 资源与兜底

| 场景 | 兜底 |
|---|---|
| 摄像头初始化失败 | 跳过推流任务，其余功能继续（当前实现） |
| MAX30102 初始化失败 | 继续上报温湿度，心率字段置上一次有效值（当前实现用的是全局变量，需注意不要长期为 0） |
| 舵机初始化失败 | 跳过云台任务 |
| 语音不可用 | 保持 HTTP 回退路径；WS 失败不影响整机 |
| Wi-Fi 断开 | 事件回调里直接 `esp_wifi_connect()` 重连（当前实现）；建议加次数上限与 30 s 冷却 |
| 堆不足 | 语音环形缓冲、摄像头帧缓冲都在 PSRAM；`heap_caps_get_free_size` 低于 20 KB 时停止开新会话 |
